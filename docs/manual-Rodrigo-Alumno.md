# Manual de modelos de servicio Cloud

## Modelos de servicio Cloud: IaaS vs PaaS

| Característica | IaaS | PaaS |
|---|---|---|
| Significado | Infraestructura como servicio | Plataforma como servicio |
| Qué proporciona | Servidores, almacenamiento, redes y máquinas virtuales | Entorno preparado para desarrollar y ejecutar aplicaciones |
| Gestión del sistema operativo | La gestiona el usuario | La gestiona el proveedor |
| Control | Mayor control sobre la infraestructura | Menor control, pero mayor facilidad de uso |
| Ejemplo | Amazon EC2 | Google App Engine |
